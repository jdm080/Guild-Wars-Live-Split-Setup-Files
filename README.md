## EXP Tracker Logic

Currently the splits are setup in a way to track time at level listed. Survivor tracks time till you hit the required EXP. When you change your splits or layout you will need to reattach the script to the new split/layout! 
Currently this can only track deaths while the timer is running.

Pauses Game Timer when you are not logged into a character and during loading screens. So if you start a challenge try and take a break and then log into another character it will start the timer again. So be sure to make a note of your time so when you want to start again put that time into the "Start Timer at:  " in the Splits Editor, and then log into the character. Since this is just a read of your total Exp gained it will rush down the splits to where you need to be.

## Logic/Behavior
  Timer auto starts on zoning into an explorable. Zoning/teleporting into a town will cause a split(next section), and will pause the game timer. Pausing also will happen during your loading screens.
  
  It will keep going until it runs out of splits. So its fairly flexible if you want to make your own split just add in the explorable and town names in order.
  Just make sure its in the correct order.
